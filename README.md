# NBP Vanilla Plus
This is a mod to make Minecraft easier and more QoL, but you'll have to work for it.

_Now in early development._

### This mod includes the ability to craft a pickaxe that, under the effect of Haste II, can instantly mine deepslate (not cobbled)

![Smithing craft new pickaxe](https://cdn.modrinth.com/data/cached_images/bdacb50ca16e9b55916fb5d1252056b00b97a5d3.png)

### It also adds a few crafting recipes that I felt were missing from vanilla

![Chest craft from logs](https://cdn.modrinth.com/data/cached_images/ae346eaba5618d8457573d5d5f9acb02858f5b37.png)
![Stick craft from Bamboo Block](https://cdn.modrinth.com/data/cached_images/24bf2cefeb0bfa21ca2914085d654c536a3fb9a2.png)
